
SVS STUDY HALL WEBSITE
======================

PROJECT FILES
-------------

1. index.html  - Website structure
2. styles.css  - Website design
3. script.js   - Website functionality
4. README.txt  - Instructions


HOW TO RUN THE WEBSITE
----------------------

1. Open Visual Studio Code.

2. Select File > Open Folder.

3. Open your SVS-Study-Hall folder.

4. Install the Live Server extension.

5. Right-click index.html.

6. Select Open with Live Server.

7. Your website will open in your browser.


WHATSAPP SETUP
--------------

1. Open script.js.

2. Find:

   const WHATSAPP_NUMBER = "91XXXXXXXXXX";

3. Replace it with your official WhatsApp number.

4. Save the file.


IMPORTANT
---------

The contact form opens WhatsApp with a prepared enquiry.

It does not currently save customer enquiries
to a database.

You will need to configure the official WhatsApp
number before customers can use this feature.


BEFORE PUBLISHING
-----------------

- Add actual study hall photographs.
- Confirm membership prices.
- Confirm WhatsApp number.
- Test the contact form.
- Test the website on mobile.
- Publish the website online.
